# 📋 Smart Clipboard Manager Pro

A modern, feature-rich clipboard management application built with **Python**, **Tkinter**, and **Pyperclip**. Designed to help users efficiently manage, organize, search, and export clipboard history with a beautiful dark-themed interface.

---

## ✨ Features

### 📌 Clipboard Monitoring

* Real-time clipboard tracking
* Automatic clipboard history capture
* Consecutive duplicate prevention
* Background monitoring using threading

### 📚 Clipboard History Management

* View clipboard history in a modern interface
* Timestamp for every copied item
* Copy previous items instantly
* Edit existing clipboard entries
* Delete unwanted entries

### ⭐ Favorites System

* Mark important clipboard items as favorites
* Quick access to favorite entries
* Favorite filtering support

### 🔍 Smart Search & Filtering

* Instant search functionality
* Filter by:

  * 📋 All Items
  * ⭐ Favorites
  * 🕐 Recent Items

### 🏷️ Automatic Content Categorization

Detects and categorizes:

* 📧 Emails
* 🌐 URLs
* 📞 Phone Numbers
* 💻 Code Snippets
* 🗂️ JSON Data
* 📝 Plain Text

### 📊 Statistics Dashboard

View useful insights such as:

* Total clipboard entries
* Favorite items count
* Today's copied items
* Storage size
* Category breakdown

### 💾 Persistent Storage

* JSON-based data storage
* Automatic history saving
* Settings persistence
* History restoration on startup

### 📤 Export Functionality

Export clipboard history to:

* JSON
* CSV
* TXT

### 📥 Import Support

* Import clipboard history from JSON files

### 📝 Productivity Tools

* Built-in Quick Notes
* Ready-to-use Templates

  * Email Template
  * Address Template
  * Phone Template
  * Meeting Notes

### ⚙️ Settings Panel

Customize:

* Clipboard monitoring
* Auto-save interval
* Maximum history size
* Duplicate handling
* Timestamp visibility

### ⌨️ Keyboard Shortcuts

| Shortcut | Action               |
| -------- | -------------------- |
| Ctrl + C | Copy Selected Item   |
| Ctrl + F | Search               |
| Ctrl + D | Delete Selected Item |
| Ctrl + S | Export History       |
| Ctrl + L | Clear History        |
